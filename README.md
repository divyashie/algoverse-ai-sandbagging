# Algoverse AI Sandbagging Research
   
   Research repository for investigating AI sandbagging behaviors.
   
   ## Project Structure
```
   algoverse-ai-sandbagging/
   ├── data/
   │   ├── raw/              # Original datasets
   │   ├── processed/        # Cleaned/preprocessed data
   │   └── exploration/      # EDA outputs
   ├── models/
   │   ├── baseline/         # Baseline model implementations
   │   └── imitative/        # Imitative training models
   ├── experiments/          # Experiment configurations and scripts
   ├── notebooks/            # Jupyter notebooks for exploration
   ├── src/
   │   ├── data/            # Data processing utilities
   │   ├── models/          # Model architectures
   │   ├── training/        # Training scripts
   │   └── evaluation/      # Evaluation metrics
   ├── results/             # Experiment results and visualizations
   └── docs/                # Documentation
```
